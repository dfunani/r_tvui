Your terminal deserves a real file explorer — not another `cd` loop.

I shipped **R-TVUI v3.1.0**: a keyboard-first TUI file manager in **Rust**.

Browse folders. Preview files. Mark, move, delete (with confirm + trash). Tabs. Split panes. Git hints in the list. One small binary — no Electron, no drama.

Try it:
https://r-tvui-web.vercel.app/download

Built in public. MIT. Feedback welcome.
